### 🚀 About Me

I'm a **Full Stack & Mobile Developer** focused on building scalable, reliable, and production-ready software.

I specialize in **SaaS platforms, web applications, mobile apps, marketplaces, e-commerce, FinTech, business platforms, and AI-powered products**.
